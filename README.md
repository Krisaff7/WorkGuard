# WorkGuard — Suivi de temps et gestion du quota annuel

**Stack :** React Native · TypeScript · SQLite

Application mobile de suivi du temps de travail, conçue pour gérer un
objectif annuel de 964 heures avec une visualisation claire de la
progression. Développée durant la formation à l'IFRI.

- Suivi en temps réel du cumul des heures sur l'objectif annuel
- Chronométrage précis des sessions de travail quotidiennes
- Historique complet des sessions consultable à tout moment
- Persistance des données 100% locale via SQLite, sans connexion requise
